# 네트워크 아카데미 — 유선통신 신입 기술 교육 사이트

신입 사원이 커리큘럼 순서대로 학습하고, 문서별로 **읽음 / 이해함**을 체크하며 진도를 관리하는 교육 웹사이트입니다.
GitHub Pages로 무료 배포되며, 별도 서버나 데이터베이스가 필요 없습니다.

| 페이지 | 주소 | 용도 |
|---|---|---|
| 학습 사이트 | `https://<계정명>.github.io/<저장소명>/` | 신입·실무자가 학습 |
| 관리자 페이지 | `https://<계정명>.github.io/<저장소명>/admin.html` | 관리자가 내용 수정 |

---

## 1. 폴더 구조

```
├── index.html        학습 사이트 (수정 불필요)
├── admin.html        관리자 페이지 (수정 불필요)
├── curriculum.json   커리큘럼 정의 — 사이트 제목, Part, 문서 순서·소제목
└── docs/
    ├── 01-network-isp.md ~ 11-tech-trends.md   교육 문서 본문
    └── images/       문서에 넣는 이미지
```

내용을 고칠 때는 `index.html`이 아니라 **`docs/` 폴더의 md 파일과 `curriculum.json`** 을 수정합니다.
관리자 페이지를 쓰면 이 파일들을 직접 건드리지 않아도 됩니다.

---

## 2. 최초 배포 (한 번만)

1. GitHub에서 저장소 생성 (Public)
2. 이 폴더의 파일 전체를 업로드
   - GitHub 웹: **Add file → Upload files** 에서 `index.html`, `admin.html`, `curriculum.json`, `docs` 폴더를 드래그 → **Commit changes**
3. **Settings → Pages** 이동
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)` → **Save**
4. 1~2분 후 `https://<계정명>.github.io/<저장소명>/` 접속 확인

> ⚠️ `index.html` 파일 하나만 열면(더블클릭) 동작하지 않습니다. 교육 자료를 `docs` 폴더에서 불러오는 구조라 **웹 주소로 접속**해야 합니다.
> 내 PC에서 미리 확인하려면 이 폴더에서 `python -m http.server` 실행 후 `http://localhost:8000` 으로 접속하세요.

## 3. 관리자 페이지 사용법

### 3-1. 최초 1회 — 토큰 발급 및 연결

관리자 페이지가 저장소를 수정하려면 GitHub 액세스 토큰이 필요합니다.

1. [GitHub 토큰 발급 페이지](https://github.com/settings/personal-access-tokens/new) 접속
2. **Token name**: 아무 이름 (예: `network-academy-admin`)
3. **Expiration**: 원하는 기간 (만료되면 재발급 후 다시 입력)
4. **Repository access** → `Only select repositories` → 이 저장소 선택
5. **Permissions** → Repository permissions → **Contents** 를 **Read and write** 로 변경
6. **Generate token** → 화면에 표시된 토큰 값 복사 (이 화면을 벗어나면 다시 볼 수 없음)
7. `admin.html` 접속 → 계정명·저장소명·토큰 입력 → **연결하기**

> 🔐 **토큰은 비밀번호와 같습니다.**
> - 코드에 넣지 마세요. 저장소가 Public이라 코드는 누구나 볼 수 있습니다.
> - 토큰은 **입력한 브라우저에만** 저장됩니다. 다른 PC에서 쓰려면 그 PC에서 다시 입력해야 합니다.
> - 유출이 의심되면 GitHub 설정에서 해당 토큰을 **Revoke(폐기)** 하고 새로 발급하세요.
> - 관리자 페이지 주소를 알아도 토큰이 없으면 아무것도 수정할 수 없습니다.

### 3-2. 할 수 있는 일

| 기능 | 방법 |
|---|---|
| **소제목 수정** | 문서 선택 → 상단 '소제목' 칸 수정 → 저장하기 |
| **내용 수정** | 문서 선택 → 가운데 편집창에서 수정 (오른쪽에 실시간 미리보기) → 저장하기 |
| **학습 순서 변경** | 왼쪽 목록에서 ▲ ▼ 버튼 → 저장하기 |
| **문서를 다른 Part로 이동** | 문서 선택 → '소속 Part' 선택 → 저장하기 |
| **이미지 넣기** | 편집창 위 **🖼 이미지 올리기** → 파일 선택 (본문에 자동 삽입) → 저장하기 |
| **링크 넣기** | **🔗 링크** 버튼 → 주소 입력 (다른 교육 문서는 `02-osi-7layer.md` 처럼 파일명 입력 시 사이트 안에서 이동) |
| **새 문서 추가** | 왼쪽 아래 **＋ 새 문서 추가** → 소제목·Part·파일명 입력 |
| **문서 삭제** | 문서 선택 → 왼쪽 아래 **문서 삭제** |
| **사이트 제목·Part 관리** | 왼쪽 아래 **✎ 사이트 제목 · Part 관리** |

- 저장하지 않은 변경이 있으면 상단에 **주황색 점**이 표시됩니다.
- `Ctrl+S` (Mac은 `⌘+S`) 로도 저장할 수 있습니다.
- **저장 후 사이트 반영까지 30초~1분** 걸립니다 (GitHub Pages 배포 시간). 바로 안 보이면 잠시 후 새로고침하세요.

### 3-3. 이미지 직접 올리기 (관리자 페이지 없이)

GitHub 웹에서 `docs/images` 폴더 → **Add file → Upload files** 로 올린 뒤, 문서 본문에 이렇게 씁니다.

```markdown
![광케이블 구조도](images/optical-cable.png)
```

## 4. 학습 진도에 대해

- 진도(읽음 / 이해함)는 **학습자 본인 브라우저에 이름별로 저장**됩니다.
- 같은 PC를 여러 명이 써도 이름만 바꾸면 각자 진도가 유지됩니다.
- 다른 PC에서 접속하면 진도가 따라가지 않으며, 관리자가 다른 사람의 진도를 볼 수는 없습니다.
- 여러 명의 진도를 한곳에 모아 보려면 Google 스프레드시트 또는 Firebase 연동이 필요합니다. (별도 작업)

## 5. 자주 묻는 질문

**Q. 계속 무료인가요?**
네. Public 저장소 기준 GitHub Pages는 무료이며, 사이트 1GB·월 대역폭 100GB 한도가 있습니다. 이 사이트는 전체 200KB 수준이라 사실상 제한 없이 사용할 수 있습니다.

**Q. 내용이 외부에 공개되나요?**
Public 저장소는 코드와 교육 문서가 모두 공개됩니다. 대외비 내용이 있다면 해당 문서를 빼거나, Private 저장소(유료 플랜) 또는 사내 서버 배포를 검토하세요.

**Q. 실수로 잘못 저장했어요.**
GitHub 저장소의 **History(커밋 기록)** 에서 이전 버전을 확인하고 되돌릴 수 있습니다. 삭제한 문서도 기록에는 남아 있습니다.

**Q. 관리자 페이지 주소를 학습자가 알면 어떡하죠?**
토큰이 없으면 내용을 볼 수만 있고 수정은 불가능합니다. 다만 혼동을 줄이려면 학습자에게는 기본 주소만 공유하세요.
