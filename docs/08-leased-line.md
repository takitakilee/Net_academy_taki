# [기술 개념] 인터넷 전용회선의 구조와 운영 (프리벤·KORNET·보라넷, OLT/ONU/ONT)

---

## 문서 요약 (Summary)

**인터넷 전용회선**은 통신사 국사의 인터넷 백본망에 고객사를 전용회선으로 직접 연결하여 보장된 대역폭의 인터넷을 제공하는 상품입니다. 통신사별 인터넷 백본망 브랜드(SKB 프리벤, KT KORNET, LG 보라넷)와 수용 구조(OLT/ONU/ONT), 이중화(BGP 연동), 품질 제어(QoS)를 이해하는 것이 회선 설계·운영의 기본입니다.

---

## 핵심 개념 (Key Concepts)

### 통신사별 인터넷 백본망 브랜드

| 통신사 | 인터넷 백본망 브랜드 |
|---|---|
| **KT** | KORNET (코넷) |
| **LG U+** | 보라넷 |
| **SK브로드밴드** | 프리벤 (PremiumVEN) |

- **수용 구조 (프리벤 FBS 기준)**: 국사에 인터넷 서비스 장비가 모두 설치되어 있고, 고객사는 **국사까지 전용회선으로 접속**하는 형태
- **KREN (교육전산망, Korea Research and Education Network)**: 학교·교육기관용 인터넷망. **기술 방식과 장비는 프리벤과 동일**하며, 성격상 인터넷 회선에 해당

### 전송 방식의 전환: TDM → 메트로 이더넷

- **과거 (TDM)**: 45M / 155M / 622M 등 계위 단위로 **MSPP (Multi-Service Provisioning Platform)** 장비를 통해 제공
- **현재 (메트로 이더넷)**: **장비 하나에서 이더넷 방식으로 대역을 제공**하는 구조로 전환 — 구성 단순화, 대역 조정 유연

### 전용회선 vs 인터넷 전용회선의 생존성

- **전용회선**: 코어(광섬유) **두 가닥**으로 구성
- **인터넷 전용회선**: 회선이 끊어지면 해당 사이트는 인터넷에서 **고립**됨
- **이중화 방안**: KT / SKB 등 **복수 통신사 회선 + BGP (Border Gateway Protocol) 연동**을 구성해 두면 한 회선이 끊어져도 인터넷이 단절되지 않음 (상세: BGP 문서 참조)

## 구성 및 동작 원리 (Architecture & Mechanism)

### 1. 가입자 수용 계층: OLT → ONU → ONT

| 장비 | 역할 |
|---|---|
| **OLT (Optical Line Terminal)** | 국사 측 광선로 종단장치. **ONU의 상위 장비**로, 하나의 OLT가 수십 개의 ONU를 수용 |
| **ONU (Optical Network Unit)** | 지역/건물 단위 광 수용 장비 |
| **ONT (Optical Network Terminal)** | 가입자 측 광 단말. **공인 IP를 하나씩 할당**받아 제공 |

- 가입자 공인 IP는 **유동 IP / 고정 IP** 중 어느 방식으로 제공할지 결정 필요

### 2. 공유기와 NAT

- 공유기는 사설 IP 대역(약 **256개**, 예: 192.168.0.x/24)을 생성하고, **NAT (Network Address Translation)** 로 공인 IP 하나에 변환하여 인터넷과 통신
- 공유기의 부가 기능:
  - **MAC 정보 전달**: 하위 단말의 MAC 정보를 확인·전달
  - **방화벽 (Firewall) 기능**: 외부의 비인가 접근 차단
- 사설 IP는 대역을 바꿔 얼마든지 추가 생성 가능 (사설 IP 대역 상세: IP 주소 체계 문서 참조)
- 무선 모뎀을 가져와 고객에게 제공하는 구성 방식도 존재

### 3. QoS (Quality of Service) — 대역 제어

- 가입 대역 이상을 쓰지 못하도록 **스위치 단에서 트래픽을 억제**하는 방식으로 속도를 제어
- 예: 1G 회선 가입 시 실제 999M까지 사용해도 여유가 있는 수준으로 운영
- 전용 QoS 장비는 **수천만 원대**의 고가 장비 (속도 제어 관련 핵심 장비)

### 4. 트래픽 경로 동향

- 최근 **SKB(프리벤) 방향으로 트래픽이 쏠리는 현상**이 관찰됨 → 라우팅 관점에서 **더 빠른 경로로 선택되고 있다**는 의미

### 5. 기본 진단 명령어 (운영 실무)

| 명령어 | 용도 | 사용 예 |
|---|---|---|
| **ping** | 대상 IP와의 통신 상태·응답 시간 확인. `-t` 옵션은 중단할 때까지 무제한 반복 | `ping -t 210.220.163.82` |
| **tracert** | 목적지까지의 **경유 경로(라우터 홉) 추적** | `tracert 8.8.8.8` |
| **whois** | 해당 **IP가 어디에(어느 기관에) 등록**되었는지 조회 | `whois 210.220.163.82` |

## 실무 적용 사례 (Use Case)

- **학교(교육기관) 회선 제안**: KREN은 프리벤과 기술 방식·장비가 동일하므로, 학교 고객의 KREN 회선을 자사 인터넷 전용회선 관점에서 동일한 구성으로 검토·제안할 수 있습니다. 회선별 대역 정보를 입혀 규모(월 이용료 기준 등)별 대상 기관을 선별하는 방식으로 영업 대상을 도출합니다.
- **무중단 인터넷 구성 제안**: 인터넷 단절 시 업무가 고립되는 고객(기업·기관)에게 KT+SKB 등 이원화 회선 + BGP 연동 구성을 제안합니다.
- **장애 1차 진단**: 고객 민원 접수 시 ping(-t) → tracert → whois 순으로 구간·경로·대역 소유자를 확인해 자사 구간/타사 구간 장애를 분리합니다.

## 주의사항 및 FAQ

### 주의사항

- **단일 인터넷 전용회선의 고립 리스크**: 이중화 없는 인터넷 전용회선은 단선 시 대체 경로가 없습니다. 중요 고객에게는 반드시 회선 이원화 + BGP 구성을 안내해야 합니다.
- **IP 제공 방식 사전 확정**: 개통 전에 유동/고정 IP 여부를 확정해야 합니다. 서버 운영·VPN 고객은 고정 IP가 필수입니다.
- **QoS 정책 확인**: 체감 속도 민원 시 회선 자체 장애가 아니라 가입 대역 기준의 QoS 제어가 원인일 수 있으므로, 가입 대역과 실제 사용량을 먼저 대조합니다.

### FAQ

- **Q. 프리벤·KORNET·보라넷은 무엇이 다른가요?**
  - A. 각 통신사가 운영하는 인터넷 백본망의 브랜드 이름입니다. 고객이 어느 통신사 회선에 가입하느냐에 따라 접속되는 백본망이 달라집니다.

- **Q. KREN 회선을 쓰는 학교도 우리 장비로 수용 가능한가요?**
  - A. KREN은 프리벤과 기술 방식·장비가 동일한 인터넷 회선이므로 동일 구성으로 수용·전환 검토가 가능합니다.

- **Q. OLT와 ONU, ONT의 관계는?**
  - A. OLT(국사) → ONU(건물/지역) → ONT(가입자) 순의 상하 구조이며, 하나의 OLT가 수십 개의 ONU를 거느립니다.

- **Q. 인터넷이 안 될 때 무엇부터 확인하나요?**
  - A. ping으로 대상 응답을 확인하고, tracert로 어느 구간에서 끊기는지 추적한 뒤, whois로 해당 구간 IP의 소속을 확인해 장애 책임 구간을 분리합니다.
