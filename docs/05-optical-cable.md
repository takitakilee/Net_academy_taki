# [기술 개념] 광케이블과 광전송 기술 (WDM/DWDM)

---

## 문서 요약 (Summary)

광케이블은 유리 섬유 속으로 빛(광자)을 쏘아 데이터를 전송하는 매체로, 이론상 수십 THz 이상의 초광대역폭을 가지며 구리선과 비교할 수 없는 속도·거리·품질을 제공합니다. **WDM (Wavelength Division Multiplexing, 파장 분할 다중화)** 계열 기술은 하나의 광섬유에 여러 파장의 빛을 동시에 실어 대역폭을 극대화하며, 통신사 백본망과 전용회선 구성의 핵심 기술입니다.

---

## 핵심 개념 (Key Concepts)

- **사용 파장**: 주로 **1,260nm ~ 1,675nm 적외선 영역** 중 빛의 감쇄(Attenuation)가 가장 적은 특정 파장 대역(Windows)을 나누어 사용
- **구리선 vs 광섬유 — 물리적 차이**:

| 구분 | 구리선 (전기) | 광섬유 (빛) |
|---|---|---|
| 신호 매체 | 전기적 진동 | 빛 (광자) |
| 가용 대역 | 저항·간섭으로 고주파 전송 곤란. 전화선은 가청 주파수 300Hz~3.4kHz만 통과 (통칭 '4kHz 대역폭') | 1,310/1,490nm 파장 ≒ 약 193~229THz의 초고주파 → 압도적 대역폭 |
| 간섭 | 유도 기전력에 의한 혼신(Crosstalk) 발생 | 빛의 독립성(중첩의 원리)으로 간섭 없음 |

- **FTTH 파장 분할 (PON, Passive Optical Network)**:
  - **1,310nm**: 분산(신호 퍼짐)이 거의 없는 구간 → **상향 (Upstream)** 신호
  - **1,490nm**: 손실이 매우 적은 구간 → **하향 (Downstream)** 신호
  - 대역폭 분할로 인터넷·IPTV·인터넷전화를 동시 서비스

### 광케이블의 강점

1. **압도적 대역폭 (도로의 폭)**: THz 단위 고주파 사용으로 데이터 고속도로의 차선이 수천 배 넓음 → 다수 동시 접속에도 속도 저하 미미
2. **신호 간섭 제로 (전자기적 독립성)**: 옆에 강한 빛·전기가 흘러도 간섭 없음 → 여러 가닥을 묶어도 신호가 섞이지 않아 깨끗한 품질 유지
3. **장거리 전송**: 전기 신호는 수백 m마다 증폭이 필요하지만, 광신호는 수십 km를 가도 손실이 매우 적음
4. **보안성**: 전기 신호는 전자기파 태핑(Tapping)이 가능하지만, 광은 케이블을 물리적으로 자르지 않는 한 도청 불가

### 광케이블의 약점

1. **물리적 취약성**: 유리 재질이라 급격히 꺾이면 빛이 새어 나가거나(**매크로 벤딩 손실**) 섬유가 부러질 수 있음 → 복잡한 배선 시 곡률 반경 주의
2. **고가의 장비·설치 비용**: 광↔전기 변환 장치(광모뎀, OLT 등)가 고가. 단선 시 구리선처럼 꼬아 잇지 못하고 **융착 접속기**와 전문 숙련이 필요
3. **분기(Splitter)에 따른 신호 감쇄**: 광 분배기로 1개의 빛을 32·64분기(1→2→4→8→16→32→64→128)하면 빛의 세기가 물리적으로 약해져, 과도한 분기 시 수신 불량 발생 가능

## 구성 및 동작 원리 (Architecture & Mechanism)

### WDM 계열 기술 비교

| 구분 | WDM (Wavelength Division Multiplexing) | DWDM (Dense WDM) |
|---|---|---|
| 개념 | 하나의 광섬유에 여러 파장의 빛을 실어 보내는 기본 기술. FTTH의 1,310/1,490/1,550nm 분할이 넓은 의미의 WDM | 'Dense(고밀도)'라는 이름처럼 파장을 아주 촘촘히 배치해 초대용량 전송 |
| 파장 간격 | 넓음 | 매우 좁음 (보통 0.8nm 이하) |
| 채널 수 | 2~16개 | 80~160개 이상 |
| 기술 요건 | - | 파장 간 간섭 방지를 위한 정밀 온도 조절 장치·고성능 레이저 필요 |
| 비유 | 왕복 2~4차선 도로 | 100차선 초거대 고속도로 |

- **DWDM 도입 효과**:
  - **케이블 증설 비용 절감**: 이미 포설된 케이블 한 가닥의 효율을 100배 이상 향상
  - **초고속 전송**: 광섬유 한 가닥으로 초당 수 테라비트(Tbps) 전송
- **CWDM (Coarse WDM)**: 단거리용 광파장 다중화 방식

### 메트로 이더넷과 캐리어 이더넷

- **이더넷 (Ethernet)**: 유선 네트워크 통신 표준. 데이터를 **프레임(Frame)** 단위로 쪼개 장치 간 주고받는 규칙 (LAN 케이블 연결이 대표 사례)
- **메트로 이더넷 (Metro Ethernet)**: 도심 지역에서 국사~회사 건물을 광케이블로 연결하고, 기업 내부망과 같은 이더넷 방식으로 데이터를 주고받는 기술 — **설치가 간편하고 비용 대비 효율이 좋음**
- **캐리어 이더넷 (Carrier Ethernet)**: 이더넷을 도시·국가 단위 광역망용으로 업그레이드한 **통신사급 신뢰성** 기술
  - 장거리 전송: 데이터 손실 없이 전송
  - 품질 보장: 특정 회선에 우선순위 부여 (QoS)
  - 신속한 복구: 선로 장애 시 **50ms 이내** 예비 경로 절체

## 실무 적용 사례 (Use Case)

- **백본망·해저 케이블**: 국사 간, 국가 간 백본 구간에 DWDM을 적용해 기존 케이블의 용량을 증설 없이 확장합니다.
- **기업 전용회선 구성**: 국사에서 고객사 건물까지 광케이블 + 메트로 이더넷으로 구성하여 빠른 개통과 비용 효율을 확보합니다.
- **FTTH 가입자망**: PON 기반 파장 분할(상향 1,310nm / 하향 1,490nm)로 한 가닥 광섬유에서 인터넷·IPTV·전화를 동시 제공합니다.

## 주의사항 및 FAQ

### 주의사항

- **곡률 반경 관리**: 국사·전산실 배선 시 광케이블을 급격히 꺾으면 벤딩 손실이 발생합니다. 여러 가입자 분기 배선 시 특히 주의해야 합니다.
- **분기 설계 한도 준수**: PON 분기 수가 과도하면 광 레벨 저하로 수신 불량이 발생합니다. 분기 단수별 광 레벨을 측정·관리해야 합니다.
- **융착 접속 품질**: 단선 복구는 반드시 융착 접속기와 숙련 인력이 수행해야 하며, 접속점 손실값을 기록·관리합니다.

### FAQ

- **Q. 광케이블은 왜 구리선보다 빠른가요?**
  - A. 빛은 THz 단위의 고주파를 사용해 같은 시간에 실을 수 있는 정보량(대역폭)이 압도적으로 크고, 간섭·감쇄도 훨씬 적기 때문입니다.

- **Q. WDM과 DWDM 중 무엇을 쓰나요?**
  - A. 가입자망(FTTH)은 넓은 의미의 WDM(PON 파장 분할), 국사 간 백본·장거리 대용량 구간은 DWDM을 사용합니다.

- **Q. 광케이블도 도청이 가능한가요?**
  - A. 전기선과 달리 전자기파 방출이 없어 물리적으로 케이블을 절단·개입하지 않는 한 신호를 엿볼 수 없습니다.
