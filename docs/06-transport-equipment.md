# [기술 개념] 전송 방식의 진화와 전송장비 (TDM/패킷, MSPP/PTN)

---

## 문서 요약 (Summary)

통신망의 전송 방식은 회선을 독점하는 **TDM (Time Division Multiplexing, 시분할 다중화)** 기반에서, 데이터를 조각내어 망을 공유하는 **패킷(Packet)** 기반으로 진화했습니다. 이 과도기를 잇는 장비가 **MSPP (Multi-Service Provisioning Platform)** 이고, 패킷 기반으로 완전히 전환된 차세대 전송 장비가 **PTN (Packet Transport Network)** 입니다.

---

## 핵심 개념 (Key Concepts)

### 광 네트워크 (Optical Network)

- 광섬유를 통해 전기 신호를 빛(레이저)으로 변환하여 전송하는 네트워크
- **초고속·대용량**: Tbps급 전송 / **장거리**: 손실이 적어 해저 케이블 등 국가 간 백본망에 사용 / **WDM**: 여러 파장을 동시에 실어 대역폭을 기하급수적으로 확장

### 패킷 기반 네트워크 (Packet-based Network)

- 데이터를 **패킷**이라는 작은 조각으로 쪼개고, 각 조각에 목적지 주소·순서를 붙여 전송
- **자원 효율성**: 회선을 독점하지 않고 여러 사용자가 망을 공유 → 대역폭 낭비 없음
- **유연성**: 패킷마다 최적 경로를 동적으로 선택 → 장애 시 우회 전송 가능
- 대표 기술: IP(인터넷), 이더넷(Ethernet)

### 전송 방식 비교: TDM(E1) vs 패킷

| 구분 | E1 / TDM 방식 — "VVIP 전용차로" | 패킷 방식 — "효율성 끝판왕 택배 시스템" |
|---|---|---|
| 개념 | 유럽식 디지털 전송 표준, 2.048Mbps 고정 속도 | 모든 데이터를 패킷으로 쪼개 전송 (IP망, 이더넷, PTN) |
| 동작 | 나와 목적지 사이에 **전용 회선을 예약** (회선 교환) | 전용 회선 없이 **공용 대역폭을 공유**, 주소(IP/MAC)를 보고 빈 길로 이동 (패킷 교환) |
| 장점 | 지연·끊김 없음, 보안·신뢰성 극도로 높음 | 회선 효율 극대화, 대용량 처리 유리 |
| 단점 | 회선이 비어 있어도 남이 못 씀 → 대역폭 낭비 심함 | 트래픽 집중 시 지연 발생 → **QoS (Quality of Service)** 제어 필수 |

## 구성 및 동작 원리 (Architecture & Mechanism)

### MSPP (Multi-Service Provisioning Platform) — "구형 화물과 신형 택배를 동시에 싣는 하이브리드 열차"

- **등장 배경**: TDM 기반 SDH/SONET 망과 패킷 기반 망의 **통합 필요성**. 트래픽 증가와 인프라 복잡화로 단일 장비에서 다중 서비스를 제공해야 하는 요구 발생
- **목적**: 인프라 단순화, 운영 비용(OPEX) 절감, 다양한 서비스 동시 제공
- **역할**: 과거에는 E1 전용 장비와 이더넷 전용 장비를 따로 두어야 했으나, MSPP는 **하나의 광 전송 장비에서 E1(TDM) 신호와 패킷 데이터를 동시에 수용·처리**. 구형 교환기(E1)를 쓰는 지사와 최신 PC(이더넷)를 쓰는 본사를 하나의 장비로 광망에 연결하는 브릿지 역할
- **TDM 동작 원리**: 하나의 선로에서 1초를 미세하게 쪼개어 여러 사용자의 데이터 전송 공간을 시분할로 할당
- **구성 요소**:

| 구성 요소 | 기능 |
|---|---|
| SDH/SONET 인터페이스 | 전통 TDM 기반 서비스 지원 |
| Ethernet 스위칭 | 데이터 트래픽 처리 |
| MPLS 지원 | 패킷 기반 전송 및 QoS 보장 |
| 광 인터페이스 | 광섬유 네트워크 연결 |
| NMS (Network Management System) | 장비 설정, 성능 모니터링, 장애 처리 |

- 안정성이 오래 검증되어 **금융권 등에서 선호**

### PTN (Packet Transport Network) — "기차의 정확함을 갖춘 택배 트럭"

- **정의**: 전통 전송망 기술(SDH/SONET)과 패킷 교환 기술(Ethernet/IP)의 장점을 결합한 **패킷 기반 지능형 전송 장비**
- **등장 배경 — "데이터 폭발"**: 음성 중심 망 설계에서 스마트폰·영상 스트리밍으로 데이터 트래픽이 폭증하며 유연성(가변 트래픽 대응)·고용량(비용 효율)·신뢰성(전송망 수준의 엄격한 관리)이 동시에 요구됨. 전화·TV·인터넷이 모두 데이터화(IP 중심 통합)된 것도 배경

#### PTN의 4대 핵심 특징

1. **MPLS-TP (MPLS Transport Profile)**: 데이터에 '라벨'을 붙여 복잡한 IP 주소를 매번 확인하지 않고 **미리 정해진 경로(터널링)** 로 빠르고 안전하게 전송 — 안정성과 효율성을 동시 확보
2. **50ms 이내 자동 절체 (Protection Switching)**: 광케이블 단선 시 **0.05초 이내** 우회 경로로 전환 → 사용자가 끊김을 인지하지 못함
3. **강력한 QoS**: 인터넷 전화, 금융 데이터, 일반 웹 트래픽을 구분하고 혼잡 시 중요 데이터에 우선순위 부여
4. **OAM (Operation, Administration and Maintenance)**: 망 상태를 실시간 감시하고 장애 지점을 정확히 탐지하는 강력한 운영·관리 기능. 소프트웨어 조작으로 용량을 유연하게 조절 가능

### 통신망 진화의 흐름 (요약)

| 시기 | 방식 | 특징 |
|---|---|---|
| **과거** | E1(TDM) 신호를 모아 광 네트워크로 전송 | 안정적이나 비효율적·저속 |
| **과도기** | MSPP 도입 — 광 고속도로 위에 'E1 전용차로'와 '패킷 혼용차로'를 동시 운영 | 기존 E1망을 유지하며 패킷 수용 |
| **현재·미래** | PTN 등 100% 패킷 기반으로 전환 | 대용량(영상·클라우드·AI) 트래픽을 극강의 효율로 처리 |

- 현재 대규모 기업망·공공기관은 안정성이 검증된 MSPP를 주력으로 쓰면서, 점차 패킷 중심 PTN·대용량 DWDM 장비와 병행 운영하는 추세

## 실무 적용 사례 (Use Case)

- **금융권·공공기관 전용회선**: 무중단·보안이 최우선인 고객에게는 검증된 MSPP 기반 회선을 제공하고, 신규 대용량 수요는 PTN으로 수용합니다.
- **E1 레거시 수용**: 고객사의 구형 교환기(E1)와 본사의 이더넷 망을 MSPP 하나로 광망에 통합 수용합니다. (관련: PSTN·E1 문서)
- **백본 이중화**: PTN의 50ms 자동 절체와 링 구조를 활용해 백본 구간 장애 시에도 서비스 무중단을 보장합니다.

## 주의사항 및 FAQ

### 주의사항

- **QoS 설계 필수**: 패킷 방식은 트래픽 집중 시 지연이 발생하므로, 음성·금융 등 지연 민감 서비스는 반드시 QoS 정책을 설계해야 합니다.
- **레거시 혼용 구간 관리**: MSPP(SDH 기반)와 PTN(패킷 기반) 혼용 구간에서는 신호 매핑·CES 설정 차이를 확인해야 합니다.
- **TDM 종료 대비**: 통신망은 패킷 기반으로 이행 중이므로, E1 기반 신규 구축보다 패킷 전환 로드맵을 고려해야 합니다.

### FAQ

- **Q. MSPP와 PTN의 차이를 한 줄로 요약하면?**
  - A. MSPP는 **SDH(전화망 방식)를 기반으로 이더넷을 얹은** 과도기 장비, PTN은 **처음부터 이더넷(패킷) 기반으로 설계하되 MSPP급 안정성을 결합한** 차세대 장비입니다.

- **Q. 패킷 방식이 효율적이라면 왜 TDM을 아직 쓰나요?**
  - A. TDM은 고정 대역폭으로 지연·끊김이 없어 음성·금융 등 레거시 서비스의 안정성 요구를 충족하며, 기존 장비 자산이 남아 있기 때문입니다.

- **Q. PTN의 '터널링'이란 무엇인가요?**
  - A. MPLS-TP 라벨로 미리 정해진 경로를 따라 데이터를 보내는 방식으로, 매번 IP를 조회하는 것보다 빠르고 경로가 보장되어 안전합니다.
