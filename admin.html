GitHub 저장소 연결

문서를 수정하려면 GitHub 저장소에 접근할 수 있는 토큰이 필요합니다.

⚠️ 토큰은 비밀번호와 같습니다. 이 페이지 코드에는 저장되지 않고, 지금 쓰는 브라우저에만 보관됩니다. 다른 사람에게 알려주지 마세요.
  1. GitHub 토큰 발급 페이지 열기
  2. Repository access → Only select repositories → 이 저장소 선택
  3. Permissions → Repository permissions → Contents 를 Read and write 로 설정
  4. Generate token 후 나오는 값을 위에 붙여넣기
